# CardioCheck

¡Bienvenido/a! **CardioCheck** es una aplicación de escritorio y móvil diseñada para realizar el **Test de Ruffier**, permitiendo a los usuarios evaluar su condición física y su capacidad de recuperación cardíaca de forma rápida y sencilla, sin necesidad de realizar una consulta médica presencial para este chequeo básico.

## 📋 Descripción

El proyecto automatiza el cálculo del Test de Ruffier-Dickson. A través de la introducción de tres frecuencias cardíacas clave (en reposo, inmediatamente después del ejercicio y tras un minuto de recuperación), la aplicación procesa los datos y entrega un resultado inmediato sobre el estado de forma cardiovascular del usuario.

## 🛠️ Tecnologías Utilizadas

Este proyecto ha sido desarrollado utilizando las siguientes tecnologías:

* **Python 3.12:** Como lenguaje de programación principal para la lógica del negocio y el cálculo del test.
* **Kivy Framework:** Para el desarrollo de la interfaz gráfica de usuario (GUI) moderna, interactiva y multiplataforma.
